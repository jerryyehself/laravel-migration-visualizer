# 歷史對話與隱私

逐字對話與來源 manifest 已移出版本化檔案，保留於維護者的本機私人備份。這些文字包含本機路徑、私人任務連結與對話識別碼，不是公開專案文件。

接手請讀 [決策索引](../DECISIONS.zh-TW.md)、[交接文件](../CLOUD_HANDOFF.md)、AGENTS.md 與各 milestone 教學；必要的架構與範圍決策仍保留。不要假設私人備份會隨 clone 傳送，也不要把歷史對話視為新的授權。

注意：移除目前檔案不會移除舊 commits、分支、PR diff 或既有 release 附件中的副本。來源 repo 公開前仍須處理這些副本，詳見 [公開前檢查](../publication-audit.zh-TW.md)。
