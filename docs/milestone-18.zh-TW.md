# Milestone 18：資料表搜尋與聚焦

每張 ERD 增加資料表搜尋與聚焦清單。搜尋忽略大小寫與首尾空白，採字面子字串比對；不使用 regex，不隱藏任何圖形或外鍵。

## React 與分層

query 是各 SchemaGraph 的本地 state，僅控制聚焦按鈕清單。GraphView 的 focused、pan、zoom 是畫面資料；比較模式透過 props 讀寫父層共用 state，所以從任一圖聚焦，兩圖視野同步。

graph-focus.ts 是純 web 呈現函式：根據真實卡片高度與目前移動後的座標，計算置中的平移與適當縮放。不解析 PHP、不重算 schema，不修改位置 overrides 或 core 結果。Core 0.5.0、JSON 與 golden 契約不變。

聚焦後藍色邊框標記目標，並將鍵盤焦點移到該卡片，可立即使用方向鍵。DOM refs 用 Map 保存特殊表名。視窗捲到畫布，其他表與外鍵仍保留；單側不存在的表不補畫。

## 行為與限制

- 找不到表有提示，圖形保持完整；清除搜尋只重設 query，不重設視野。
- 重設圖形清除選中表、位置與縮放，但保留搜尋文字。切換快照會全部重設。
- 比較模式搜尋文字各自獨立，聚焦與視野共用；圖只列出該側確實存在的表。
- 聚焦小表使用 100%，大表降低縮放；仍受 15% 下限限制，極長表可能無法完整放入畫布。
- 聚焦可能將其他表移到視野外，不代表刪除／篩除；可平移或重設回全圖。
- 按鈕清單可捲動，但沒有虛擬列表，大型專案尚未壓力測試。沒有欄位搜尋、布局持久化、timeline、AI 或 runtime 執行。

## 驗證

346／346 tests（新增 4 個 focus tests）、typecheck、build 通過。涵蓋大小寫／空白／字面符號／特殊表名、移動後置中、不可變 overrides、長表縮放界限與重設。

瀏覽器確認搜尋 USER 只列 users，posts／外鍵仍在圖中；聚焦 users 兩圖 transform 與藍色標記同步。方向鍵移動後再次聚焦採新位置；無結果不減少節點，單側 posts 聚焦不補前圖。重設清除選中標記，單圖聚焦正常，console 無 warn/error。

下一階段建議加入表的欄位／索引／外鍵詳細檢視，讓長名稱與屬性不必只靠 JSON 查看。
